# Стиль JIVA — требования и план (v2, 2026-11-11)

Рефы — Y2K / Frutiger 2000s clean tech corporate, корпорация JIVA из Dreamfall: «будущее, каким его видели
в 2000-х», тонко, стеклянно. Последние рефы от владельца (AI-рендеры): глубокое насыщенное синее небо,
стеклянные ленты-дуги по бокам, уходящие в глянцевый пол с отражениями, перспектива к горизонту.

## Что не устраивало в v1 (светлая схема особенно)

- Пересвет (overblown): аддитивный белый свет, линии через центр без смысла.
- На телефоне «лесенки»: фон рисовался в 0.5 CSS-разрешения (при DPR 3 — ~1/6 пикселей).
- При открытии клавиатуры фон сплющивался (канвас по innerHeight, кривые считаются от высоты).
- Импульсы мышления — круглое пятно-спрайт.
- Выбранный пункт («Текст», «Новый чат») — пластиковая таблетка.
- Акцент (тумблеры, слайдер, галочки) бледный.

## Что должно быть

- **Пространство:** нижняя часть — глянцевый пол с отражениями и бликами; горизонт; небо с глубиной
  (насыщенный синий сверху, светлее к горизонту). Без пересвета — читаемость важнее.
- **Ленты:** осязаемые стеклянные ленты с объёмом — ширина по перспективе, стеклянное тело, яркий тонкий
  блик по освещённой кромке, переливчатая кромка (голубой → сиреневый → розовый), мягкий ореол.
  По бокам, обрамляя центр, уходят в пол. Отражаются в полу.
- **Импульсы («макаронины»):** вытянутый световой участок вдоль ленты (10–20% длины), яркая голова,
  затухающий хвост, лёгкий glow; разные направления и скорости по лентам, реже. При мышлении — чаще и
  быстрее (вторая серия импульсов), не круглые пятна.
- **Выбранный пункт — подсвеченное стёклышко:** почти прозрачное, чуть «запотевшее» тело; светится весь
  ободок (ярче со стороны «фонарика»/лазера у среза) и немного внутрь. Только CSS (градиентная рамка,
  inset/outer glow), без backdrop-filter.
- **Акцент** насыщенный дневной синий → голубой (как на рефах); отдельный токен стиля, classic не трогаем.
- **Тёмная схема:** палитра устраивает, но та же философия — пол, ленты, стёклышки, импульсы.
- **Мобильный:** без лесенок; клавиатура не трогает фон; своя композиция для портрета.

## Архитектура (согласовано)

«Запекание на устройстве», `resources/js/backgrounds/jiva.js`, WebGL1:
1. Статичный слой рендерится один раз (открытие, смена схемы, смена ширины/поворот) в текстуру
   в разрешении экрана (DPR ≤ 2): проход неба/пола + ленты мешами (triangle strip вдоль кубических
   Безье, профиль поперёк — аналитический, сглаженный) + отражения (те же меши, зеркально по горизонту,
   мягче). Смешивание «screen» (ONE, ONE_MINUS_SRC_COLOR) — свет не выгорает. Печётся полосами
   (scissor) по кадру за раз — без рывка; готово → плавное появление.
2. Из него — размытая копия в 1/4 (ping-pong гаусс) для матового стекла под панелями.
3. Каждый кадр: композит (текстура + матовое под v-frost-панелями из размытой копии + отсвет под
   панелями) и импульсы — мешами по тем же кривым, только пиксели у линий. 30 fps в покое, 60 —
   когда модель отвечает или двигаются панели.
4. Смена схемы/размера — новое запекание во вторую текстуру и кроссфейд, старая удаляется.
5. Канвас: контейнер `fixed top-0 h-lvh` — клавиатура не меняет его размер; размер по clientWidth/Height.
6. Композиции: LANDSCAPE и PORTRAIT (aspect < 0.9); x задаётся в долях полуширины.
7. API модуля: `create(canvas, { getThinking, getTheme, onReady })` → `{ redraw, destroy }`;
   destroy удаляет текстуры/FBO/буферы/программы и делает loseContext.

Общие помощники — `backgrounds/gl.js`: `createProgram`, `frostCollector`, `FROST_GLSL`, `runShader` (classic).

## v3 (2026-11-11) — решения владельца и порядок

Светлая схема — **дневная синяя, не молочная**: прозрачное синеватое стекло с глянцевым бликом по верху,
**белый текст везде** (и на стекле), сквозь стекло видны размытые колонны. Выбранные пункты и кнопка
отправки — **«карамельки»** (Aqua/Frutiger Aero): насыщенное синее тело, резкий белый глянец в верхней
половине, светящееся дно, яркий голубой ободок, цветное свечение. Тёмная схема — тот же принцип.

1. **Ресайз:** внутреннее разрешение канваса меняется сразу (подложки не уезжают); запечённая сцена
   при ресайзе не растягивается, а совпадает по высоте и обрезается/продлевается по бокам («окно в сцену»);
   композиция задана в абсолютных единицах высоты — фигуры не сплющиваются. Перепекание — после паузы, кроссфейд.
   **Импульсы** — тонкая струя 1–2 px по ребру (освещённой кромке) ленты + лёгкий ореол, не «шланг».
2. **Карамельки и дневное синее стекло** светлой схемы (токены в app.css + frost-палитра в jiva.js).
3. **3D-колонны** без three.js: своя 3D-геометрия (закрученная лента с толщиной, опирается на пол),
   перспективная камера с фиксированным вертикальным FOV («окно в сцену»), стеклянный шейдинг (Френель,
   блик, переливчатая плёнка, полупрозрачное тело), отражение в полу. Всё — в запекании (раз), импульсы — по
   рёбрам колонн. Если не выйдет — альтернатива: композиция из картиночных слоёв.

**Статус v3:** шаги 1 и 2 сделаны (ресайз «окном в сцену», импульсы по кромке, дневная синяя схема
с белым текстом, карамельки — `--pill-*`, отправка — тоже `pill-active`). Следующий — шаг 3, 3D-колонны.

## Шаг 3 — 3D-колонны: технический план (для продолжения после компакта)

Владелец одобрил: «Поехали про 3D backdrop» (2026-11-11). Без three.js. Деплой пока не делать.

**Как устроен `resources/js/backgrounds/jiva.js` сейчас (v3):**
- WebGL1. Программы: `sky` (небо/пол, fullscreen), `ribbon` (меши лент, RIBBON_VERTEX/RIBBON_FRAGMENT,
  screen-blend `ONE, ONE_MINUS_SRC_COLOR`, uMirror — отражение относительно горизонта), `blur`, `composite`
  (cover(res) — «окно в сцену», frost из размытой копии, отсвет под панелями), `pulse` (тонкая струя по кромке, uLit).
- Запекание: `startBake()` → `bakeStep()` 6 полос scissor за кадры → blur 4 прохода (1/4) → `current`, кроссфейд `fade`.
- Композиции `LANDSCAPE`/`PORTRAIT` (`unit` — единиц высоты на долю полуширины, `horizon`, `ribbons[]`
  с p (Безье 2D), w, glow, lit, hue, gain, reflect, pulse{speed,dir,period,len,phase}). Меш: `ribbonMesh(ribbon, unit)` —
  атрибуты aPos(2) aAcross aT aW aS, stride 24 байт, TRIANGLE_STRIP, SEGMENTS=220.
- Палитры `PALETTES.light/dark` (skyTop, skyHorizon, floorFar, floorNear, horizonGlow, horizonStrength, floorShine,
  rims[3], body, pulse, exposure, frostTint, frostMix, frostDim, vignette).
- Ресайз: размер канваса сразу, перепекание через 250 мс (`onResize`). DPR ≤ 2. API `create(canvas,{getThinking,getTheme,onReady})`.

**Что делаем:**
1. Камера: перспектива, вертикальный FOV ~40°, глаз чуть выше пола, смотрит на горизонт. Мир: пол y=0,
   колонны стоят на полу. Проекция → p-space (x по высоте экрана, центр 0) — тогда cover(), горизонт и
   «окно в сцену» сохраняются. Горизонт = проекция бесконечности пола → вычислить и подставить в sky (uHorizon).
2. Колонны: 2 большие по бокам (как на рефе — вырастают из пола, изгибаются вверх и наружу), опционально
   арка-лента в небе. Геометрия — «скрученная лента»: центральная кривая (Безье 3D), ширина w(t), поворот
   сечения φ(t) (закрутка ~0.5–1 оборота), толщина малая. Генерить квад-стрип с атрибутами: позиция 3D, нормаль,
   t, сторона (edge/центр). Две грани + рёбра.
3. Шейдинг (в запекании, screen-blend): Френель по N·V (кромки ярче под скользящим углом), блик (Блинн-Фонг от
   источника сверху-сбоку), переливчатая плёнка на рёбрах (палитра rims по t/углу), полупрозрачное тело (body,
   малая альфа), лёгкий внутренний градиент. Отражение: та же геометрия, отражённая y→-y, с затуханием и мягче.
4. Импульсы: тонкие струи по РЁБРАМ колонн (линии вдоль кромки, проекция на экран), comet() как сейчас.
   Удобно: генерировать отдельные «рёберные» линии-меши (экранная толщина через вершинное смещение в p-space).
5. Портрет — та же сцена, камера та же: колонны частично за краями (не сплющиваются).
6. Проверить: светлая/тёмная, десктоп 1600×900, телефон 430×932 (cdp.py в scratchpad: `python3 cdp.py scenario.py W H mobile`,
   пробный юзер probe@availia.test / probe-pass-123 — создавать через tinker и удалять после), ресайз, тесты.
Если 3D не даст качества — альтернатива: композиция из картиночных слоёв.
